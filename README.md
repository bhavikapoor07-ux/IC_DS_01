# IC_DS_01
This internship project predicts whether a passenger survived the Titanic disaster using machine learning. It also predicts missing age values to improve model accuracy using Random Forest Regressor. The project focuses on handling the missing values of other columns too and leverages Random Forest Classifier to predict survival.

## 📘 Problem Statement
Predict survival of passengers aboard the Titanic using demographic and travel data.

## 🎯 Project Objectives
* Predict passenger survival on the Titanic using supervised machine learning techniques.
* Estimate missing age values using Random Forest Regressor to improve data quality and model performance.
* Analyze the impact of key features such as age, gender, class, and fare on survival outcomes.
* Implement an end-to-end machine learning workflow including data preprocessing, modeling, and evaluation.

## 📂 Dataset
The dataset used is the Titanic dataset from [Kaggle](https://www.kaggle.com/c/titanic/data)

## 📊 Key features used in the model
- Pclass (Passenger class)
- Sex
- Age
- SibSp (Number of siblings/spouses aboard)
- Parch (Number of parents/children aboard)
- Fare
- Embarked (Port of embarkation)

## ⚙️ Methodology
1. **Data Cleaning**: Handled missing values for Age using Random Forest Regressor.
2. **Feature Engineering**: Converted categorical features to numerical format.
3. **Modeling**:
   - **Random Forest Regressor** → Predicted missing Age values.
   - **Random Forest Classifier** → Predicted survival (Survived / Not Survived).
4. **Evaluation**: Assessed model performance using accuracy, precision, recall, F1-score and ROC-AUC Score.

## 📈 Results
- Accuracy of Random Forest Classifier as per ROC-AUC Score: 90% (approx.)
- Important features affecting survival: Sex, Pclass, Age, Fare

## 💻 Technologies
Python (Pandas, NumPy, Scikit-learn)
